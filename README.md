# The Long Roast: Lawmakers and the File They Cannot Convert

One satirical sentence roasting lawmakers who would regulate AI, crypto, or
the internet but cannot convert a file to PDF — written for the make.fun
bounty of the same name.

## How to run

Requires Node 22.18 or later (runs the TypeScript directly, no dependencies):

```sh
node main.ts
```

The program writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to `/output/entry.txt`), and refuses to write anything
outside the 1–320 character gate.

## The roast

> Congress spent three years writing a 400-page law to govern artificial intelligence, then called an emergency hearing because the bill's PDF wouldn't open — and nobody in the room had ever right-clicked a .docx and chosen Save As.
